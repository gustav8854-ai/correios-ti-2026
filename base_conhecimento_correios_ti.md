## Desenvolvimento de Sistemas (núcleo)
- **Engenharia de software:** processos; engenharia de requisitos; princípios **SOLID** (S responsabilidade única, O aberto/fechado, L Liskov, I segregação de interfaces, D inversão de dependência); design patterns (GoF, GRASP).
- **Arquitetura:** camadas, cliente/servidor, **microserviços**, orientação a eventos, serverless, hexagonal; anti-padrões; HTTP, SSL, DNS, balanceamento, escalabilidade, tolerância a falhas.
- **Desenvolvimento:** linguagens (Java, JavaScript, Python, PHP, Go); frameworks (Spring, Hibernate, Angular, Laravel); web e mobile; **containers (Docker, Kubernetes)**; integração (REST, SOAP, mensageria — Kafka, RabbitMQ — webhooks).
- **Testes:** unidade, integração, sistema; **TDD**; automatizados (xUnit, Selenium); princípios FIRST; testabilidade.
- **Qualidade:** métricas, análise estática/dinâmica, atributos de qualidade.
- **Segurança no dev:** security/privacy by design; criptografia (simétrica × assimétrica; hash); **autenticação × autorização**; OAuth2, SSO, Keycloak; segurança web/mobile.
- **Dados e IA:** Big Data, ETL, modelagem dimensional, BI, Data Mining; IA/ML, deep learning, LLM, PLN.
- **Ágil e DevOps:** **Scrum** (PO, Scrum Master, Sprint, eventos), Kanban; **CI/CD**; observabilidade; automação; Linux; **Git**.
- **Tendências:** blockchain; **nuvem (SaaS/PaaS/IaaS)**, migração e escalabilidade.
- **Spring/APIs:** Spring Boot/Cloud, Eureka, Zuul/Gateway, Swagger; API RESTful; JSON; Service Discovery. Persistência: JPA, Hibernate, Flyway. Autenticação: SSO, Keycloak, OAuth2.

## Conceitos de Computação (base técnica)
Sistemas operacionais (processos, memória, Linux); redes (TCP/IP, HTTP=80/HTTPS=443, DNS, OSI 7 camadas, TCP×UDP); banco de dados (relacional × NoSQL, SQL/JOINs, normalização, PK×FK); segurança (confidencialidade/integridade/disponibilidade).
